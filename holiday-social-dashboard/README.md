# Holiday Beverages: social media presence dashboard

Static snapshot of the Holiday Beverages dashboard, with data from Mia to 23 Nov 2026.
No build step. Open `index.html` or deploy the repo root to Vercel as a static site.

## Images (add these before going live)

The page expects these files in `images/` and hides any that are missing:

hero.webp, can-cosmo.webp, can-peach.webp, can-watermelon.webp,
photo-sunshine.webp, photo-friends.webp, photo-flavour.webp, photo-holiday.webp, logo.webp

## Updating the figures

All figures live in the `DATA` object near the bottom of `index.html`.
